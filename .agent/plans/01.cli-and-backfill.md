# Plan 01 — CLI and 70C backfill

Repo: claude-session-telemetry · Profile: interactive session, Sonnet coordinator (`claude --model sonnet`) · Reference: the project doc "claude-session-telemetry — KPI definitions and phased plan" (sections 2, 4, 5, 7).

## Goal

`cst report` reads Claude Code transcripts and writes `telemetry.json` (schema 1.0), appends one line to `runs.jsonl`, and renders `telemetry.html`. Backfilling plan 70C reproduces the "70C Session Telemetry" artifact within rounding.

## Rules

A script counts, a model never does: every figure comes from code in `src/`, never from reading a transcript in the conversation. Never commit real transcripts; tests use synthetic fixtures from `tests/fixtures/`. Every KPI is one function in `kpis.py` with one test. Do not spawn subagents; run tests in the foreground.

## Tasks

T1 Discovery. `discover.py`: given `--session <id>`, `--plan <name>` or `--project <path>`, find the session transcript and its subagent transcripts under `~/.claude/projects/`. Handle both the flat layout and the per-session subfolder layout; log which was used. Test: fixtures for both layouts.

T2 Parsing. `parse.py`: JSONL → normalised records (timestamp, role, model, agent name, usage counters, tool_use/tool_result ids). Ignore malformed lines with a count. Test: a 20-line fixture covering every record type.

T3 Gaps and time. `gaps.py`: idle classification per section 4.1 with the 2-minute threshold as a config value; active, coordinator, subagent and tool time. Test: fixture with one user-wait gap, one overhead gap, one sub-threshold gap.

T4 Attribution and tokens. `attribute.py` + `kpis.py`: per-agent and per-model totals, coordinator share, mean and peak context per coordinator call, USD from `prices.toml`. Test: totals equal hand-computed values on the fixture.

T5 Phases. `phases.py`: boundaries from `STATE.md` checkpoint entries and branch commit timestamps; graceful fallback to a single "session" phase when neither exists. Test: fixture STATE.md + synthetic git log.

T6 Output. JSON schema `schema/telemetry-1.0.json`, validation, `runs.jsonl` append (idempotent per run id), Jinja2 HTML render reproducing the 70C layout. Test: rendered HTML contains every phase row; JSON validates.

T7 CLI and backfill. `cli.py` with `report`, `trend` (table across `runs.jsonl`). Run `cst report --plan 70C` against the real EngineerLM transcripts (locally, output not committed to this repo) and compare with the artifact; record deviations and their causes in `docs/backfill-70C.md` (figures only, no transcript content).

T8 Fixture generator. `cst anonymise <transcript>`: preserves timestamps, models, agent names, usage and tool names; replaces all text with placeholders. Use it to produce the committed fixtures.

## Gates

`uv run ruff check && uv run ruff format --check && uv run pytest` green on Linux and Windows CI. 70C backfill within ±1% on tokens, ±0.5 min on durations. README shows a screenshot rendered from a fixture. Tag `v0.1.0`.
